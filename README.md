# Stat184_43

This repository is a supporting folder for 43.qmd, a Quarto file for Dr. Neil Hatfield's STAT184 class
that contains data visualizations and analysis for Diamonds data, Monte Carlo Integration, NCAA Women's Basketball Data, and the effect of GenAI on the visualizations of a calcium in humans study.
It contains (alongside 43.qmd) 43.pdf, the pdf rendering of 43.qmd, and 4 separate PNG files/3 CSV files that are used in 43.qmd.

The data comes from the Diamonds data ingrained into R and the 3 CSV files given.

The purpose of the project is to set up a remote repository for the 43.qmd file and supporting files.

The repo is not currently organized into groups, but the files that are needed are clearly listed out.
